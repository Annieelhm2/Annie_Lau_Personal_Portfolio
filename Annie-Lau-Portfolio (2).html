The question

How well can a simple regression model explain medical insurance charges using individual attributes?

From CSV to model

  • Loaded insurance.csv with pandas and inspected data types, nulls, and distinct values.
  • Explored charge patterns by age, BMI, sex, smoking status, and region.
  • Engineered six features: age, BMI, BMI², smoker, sex, and a smoker × BMI interaction.
  • Trained linear regression with a reproducible 70/30 train–test split.
  • Reported held-out MAE, RMSE, and R².

What this work demonstrates

Data inspection, feature engineering, reproducible experiments, and explicit model evaluation—the foundations I’m building on as I work towards data engineering.

Reading the results responsibly. R² measures explained variance; it is not a prediction accuracy rate. These are the notebook’s reported results from one random split. Error values use the dataset’s charge units. This is an educational project, with no claim of UK population validity or production readiness.

Source: Kaggle’s Medical Cost Personal Dataset, as linked in the repository. The notebook credits light AI assistance for discovering library functions; the modelling choices and analysis are Annie’s own.

Technical reflections & next steps

Strengthen the experiment

Future improvements would include cross-validation, a simple baseline comparison, and residual analysis. Feature exploration currently happens before the split; separating training-only exploration would make the evaluation more rigorous.

Develop the engineering side

A next iteration could move the notebook workflow into a tested pipeline with schema validation, versioned inputs, and repeatable runs. These are proposed improvements, rather than capabilities of the current repository.
